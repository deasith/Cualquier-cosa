# Cualquier-cosa — Landing page para vender tus servicios

Una página lista para usar (`index.html`) pensada para **vender servicios o productos digitales**: diseño, web, marketing, contenido, cursos, plantillas... lo que ofrezcas.

> ⚠️ Importante: la página es una **herramienta de venta**, no imprime dinero sola. Ganas dinero cuando le pones tu oferta real, la publicas y la compartes con clientes potenciales.

## Cómo usarla

1. Abre `index.html` en tu navegador para verla.
2. Personaliza el texto:
   - **`Tu Marca`** → tu nombre o el de tu negocio.
   - **Servicios** → lo que tú ofreces.
   - **Precios** → tus tarifas reales.
   - **Opiniones** → testimonios reales cuando los tengas.
3. Conecta el cobro (elige una):
   - **Stripe Payment Links**, **PayPal.me**, **Gumroad** o **Lemon Squeezy**.
   - Copia tu link de pago y ponlo en los botones `Elegir ...` (reemplaza el `href="#contacto"`).
4. Configura el contacto:
   - En el `<script>`, cambia `TU_EMAIL` por tu correo real (el formulario abre un email hacia ti).
   - O conéctalo a **Formspree** / **Google Forms** si quieres recibirlo sin abrir el correo.

## Cómo publicarla gratis

- **GitHub Pages**: Settings → Pages → Deploy from branch → `main` / raíz. Tendrás una URL pública en minutos.
- Alternativas: **Netlify** o **Vercel** (arrastra la carpeta y listo).

## Cómo conseguir clientes (lo que de verdad genera ingresos)

1. Publica la URL en tu bio de Instagram / TikTok / LinkedIn.
2. Muestra tu trabajo con ejemplos reales.
3. Escribe a gente que necesite tu servicio con el link.
4. Pide una opinión a cada cliente y añádela a la sección de "Opiniones".
